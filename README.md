# Brian Odle

I build practical machine learning and computer vision projects with an emphasis on reproducible data workflows, model training, evaluation, and deployment-oriented engineering.

My recent work focuses on computer vision systems that connect dataset infrastructure, training pipelines, model selection, MLflow tracking, FastAPI inference, and Dockerized serving.

## Featured Work

### [MLProjects](https://github.com/bodle720/MLProjects)

My main machine learning portfolio repository. It includes AWS-style computer vision dataset infrastructure, reusable training utilities, PyTorch classification projects, YOLO object detection, MLflow model selection, and deployment-oriented FastAPI/Docker workflows.

- [Computer Vision Dataset Management System](https://github.com/bodle720/MLProjects/tree/main/AWS_Tools/Computer_Vision_DMS/cvdms_cdk)  
  AWS CDK-based system for ingesting, validating, deduplicating, versioning, visualizing, and exporting computer vision datasets.

- [Global Wheat Head Detection](https://github.com/bodle720/MLProjects/tree/main/Training_Projects/projects/GlobalWheatHeadDetection)  
  End-to-end object detection project using CVDMS dataset artifacts, YOLO training, MLflow tracking, model selection, FastAPI inference, Docker deployment, latency measurement, and production-readiness discussion.

- [Training Projects](https://github.com/bodle720/MLProjects/tree/main/Training_Projects)  
  Computer vision training workflows built from reusable CVDMS dataset artifacts, including single-label classification, multi-label classification, and object detection.

- [Shared Training Utilities](https://github.com/bodle720/MLProjects/tree/main/Training_Projects/cvdms_training_common)  
  Reusable Python package for loading CVDMS metadata/manifests, images, dataloaders, metrics, training loops, and visualization helpers.

## Supporting Data Science Work

### [DSTopics](https://github.com/bodle720/DSTopics)

Notebook-based explorations of mathematical and data science topics, with an emphasis on theory, implementation, and intuition. Topics include PCA variants, ICA, DMD, multiprocessing, and other Python/data-science examples.

This repository is less deployment-focused than `MLProjects` and more focused on implementing core methods from first principles.
